# Universe Download

โปรแกรมดาวน์โหลดสำหรับ Windows วางลิงก์ได้แทบทุกแบบ ทั้งคลิปเดียว เพลย์ลิสต์ ทั้งช่อง/บัญชี อัลบั้มรูป และไฟล์ตรง จากกว่า 1,800 เว็บ (YouTube, TikTok, Facebook, Instagram, X ฯลฯ)

## ติดตั้ง
โหลด `UniverseDownload-Setup-x.y.z.exe` จากหน้า [Releases](https://github.com/Anuphat-C/UniverseDowload/releases/latest) แล้วดับเบิลคลิก
เปิดครั้งแรกโปรแกรมจะโหลดเครื่องมือที่ต้องใช้ให้เอง หลังจากนั้นโปรแกรมจะอัปเดตตัวเองอัตโนมัติ

> ตัวติดตั้งยังไม่ได้เซ็นดิจิทัล Windows SmartScreen อาจเตือน ให้กด "ข้อมูลเพิ่มเติม" → "เรียกใช้ต่อไป"

## ความสามารถ
- รายการขึ้นจอทันทีระหว่างดึง เลือกด้วยคลิก / Shift+คลิก / ค้นหา / กลับลำดับ
- โหลดพร้อมกันหลายไฟล์ ไฟล์ละหลายการเชื่อมต่อ
- เลือกความละเอียด 360p–4K หรือเสียง MP3/M4A ฝังปกและข้อมูลคลิป
- ใส่เลขตอนหน้าชื่อไฟล์อัตโนมัติ
- ทำเครื่องหมายคลิปที่โหลดแล้ว กันโหลดซ้ำ
- อัปเดตตัวโปรแกรมและเครื่องมือเบื้องหลังอัตโนมัติ

## พัฒนา
```powershell
npm install
npm start
```

## ออกเวอร์ชันใหม่
1. แก้ `version` ใน `package.json` แล้ว commit
2. `git tag v<เวอร์ชัน>` แล้ว `git push origin v<เวอร์ชัน>`
3. GitHub Actions จะ build และอัปโหลดตัวติดตั้งขึ้น Releases โปรแกรมทุกเครื่องจะอัปเดตเอง

รายละเอียดการทำงานทั้งหมดอยู่ใน [FLOW.md](FLOW.md)

## เครดิต
ใช้ [yt-dlp](https://github.com/yt-dlp/yt-dlp), [FFmpeg](https://ffmpeg.org) และ [gallery-dl](https://github.com/mikf/gallery-dl) เป็นเครื่องมือเบื้องหลัง (โหลดมาตอนใช้งาน ไม่ได้แจกจ่ายรวมกับโปรแกรม)
